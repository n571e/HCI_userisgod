一句话总结

本文提出了一种新的工作流 Social-RAG，通过检索群组的历史互动（如聊天记录、点赞），让 AI 智能体（Agent）能够"读懂空气"，生成符合群组兴趣和社交规范的内容。

核心价值

  • 解决 AI 在群组中"不知所措"的问题
  • 探索 Human-AI Collaboration
  • 让 AI 融入人类社交空间

Social-RAG 工作流程（4步）

1

Index 索引

收集群聊历史，提取"Social Facts"

例：谁分享了什么，谁点了赞
→
2

Retrieve 检索

检索相关的社交信号（Social Signals）

例："这篇论文引用了群友A上周分享的文章"
→
3

Generate 生成

利用 LLM 生成带有社交解释的推荐语

例："@张三，这篇论文和你上周分享的那篇很像"
→
4

Feedback 反馈

用户的点赞/回复成为新的历史数据

💡 技术亮点

结合向量检索（语义相似度）和启发式规则（硬性关系，如作者相同）

PaperPing 系统

核心功能

  • ✓ 自动推荐学术论文
  • ✓ 生成带社交上下文的解释
  • ✓ @提及可能感兴趣的成员
  • ✓ 链接到之前的讨论

技术栈

  • ⚡ Slack App API
  • 🤖 GPT-4-turbo (生成)
  • 📄 SPECTER (论文向量化)
  • 🔍 Semantic Scholar API
  • 💾 PostgreSQL + Node.js
🤖

设计原则

PaperPing 像一个"受邀的机器人客人"，有礼貌地融入群组，而不是主导对话

Prompt Chain 策略

Prompt 1

↓

↓
Prompt 3

理论贡献：社交接地的四个层级

Level 3

Individual-level Grounding

个人级接地：在群组中针对特定个人定制

最高级，但涉及隐私
Level 2

Group-level Grounding

群组级接地：学习特定群组的话题偏好、语气

PaperPing 的主要层面 ⭐
Level 1

Category-level Grounding

类别级接地：根据群组类型调整

粗颗粒度
Level 0

No Grounding

无接地：通用模板，对所有群组说一样的话

成本低，体验差
