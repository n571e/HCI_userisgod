# 决策卡、主题卡与行动卡关联设计文档

## 一、现状问题分析

| 卡片类型 | 现状 | 缺失关联 |
| --- | --- | --- |
| **决策卡 (Decision)** | 独立存在，仅显示“所属群聊” | 无法看到所属“主题”，无法快速跳转到相关“行动” |
| **行动卡 (Action)** | 独立存在，仅显示“所属群聊” | 无法看到所属“主题”，无法知道是为了达成哪个“决策” |
| **主题卡 (Theme)** | 包含决策/行动列表，但仅为简单的聚合 | 卡片间缺乏反向链接，创建时无法自动关联 |

**核心痛点**：信息是孤岛，用户需要手动在各个卡片间切换，无法形成“上下文流”。

---

## 二、关联模型设计

我们采用 **"星型关联结构"**，以 **主题卡** 为核心。

```mermaid
graph TD
    Theme[主题卡 (核心容器)]
    Decision[决策卡]
    Action[行动卡]
    Chat[群聊上下文]

    Theme -->|包含 1:N| Decision
    Theme -->|包含 1:N| Action
    Decision -->|属于 1:1| Theme
    Action -->|属于 1:1| Theme
    Decision -.->|衍生 1:N| Action
    Decision -->|基于| Chat
```

### 1. 字段级变更

*   **决策卡 (DecisionCard)**
    *   新增 `themeId`: 关联的主题 ID
    *   新增 `themeTitle`: 关联的主题名称（用于显示）
    *   (可选) `relatedActionIds`: 关联的行动卡 ID 列表

*   **行动卡 (ActionCard)**
    *   新增 `themeId`: 关联的主题 ID
    *   新增 `themeTitle`: 关联的主题名称
    *   (可选) `originDecisionId`: 来源决策 ID

## 三、交互设计更新

### 1. 决策卡详情页 (`DecisionCardDetail`)

*   **新增「所属主题」入口**：
    *   位置：标题下方或信息卡片区。
    *   样式：使用 `Layout` 图标 + 主题名称，点击跳转 `ThemeCardDetail`。
*   **新增「衍生行动」模块**：
    *   位置：底部。
    *   内容：列出由此决策产生的行动卡。

### 2. 行动卡详情页 (`ActionCardDetail`)

*   **新增「所属主题」入口**：
    *   同上，点击跳转主题详情。

### 3. 创建流程 (`Create...Card`)

*   **从主题卡创建**：
    *   在 `ThemeCardDetail` 点击“添加决策/行动”时，自动填入当前 `themeId`。
*   **独立创建**：
    *   新增“关联主题”选择项（下拉或搜索），允许用户手动归类。

## 五、验收标准

1.  在决策卡详情页，能看到“所属主题：版本1.2上线讨论”，点击跳转到该主题页。
2.  在行动卡详情页，能看到“所属主题：版本1.2上线讨论”，点击跳转到该主题页。
3.  从主题页进入决策/行动详情后，能通过“返回”或“所属主题”链接流畅切换。
